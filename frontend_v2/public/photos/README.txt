Drop your own photos in this folder. Use exactly these file names (jpg):

  hero1.jpg    hero2.jpg    hero3.jpg      (landing page top collage)
  strip1.jpg   strip2.jpg   strip3.jpg   strip4.jpg   (landing page photo strip)
  auth.jpg                                  (login / register side panel)

so the site always looks complete. Use photos you have the right to use
(your own, or free ones from Unsplash / Pexels).
